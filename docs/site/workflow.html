Workflow

Model, solve, review

The project revolves around one loop: define a piping model in Tuba, evaluate it with Code_Aster, then inspect processed artifacts.

  1. Define the piping model

    Build the structure in Python: routes, sections, materials, supports, loads, and operating states.

  2. Run Code_Aster

    New engineering results require a Code_Aster runtime. Exported study files are useful for diagnostics, but they do not complete the evaluation on their own.

  3. Review processed artifacts

    Solved artifacts can be reviewed in notebooks through the PyVista quick-look path or shared as a browser scene bundle through the viewer.

Visualization paths

tuba/plotting/ is the notebook and export path. tuba/visualization/ plus viewer/ is the web-scene review path. Examples should choose one path so the result boundary stays clear.
