Setup

Run locally

Use the static pages for orientation. Use a local environment when you want to solve new studies or inspect local result files.

Install the project

pip install -e ".[notebook-viz]"

Check the Code_Aster runtime

python -m tuba.solver.code_aster_doctor --check

Open the notebook

jupyter lab notebooks\10_interactive_postprocessor.ipynb

Solver requirement

Code_Aster is required for production stress, displacement, reaction, thermal-expansion, operating-state clash, compliance, and result visualization workflows. Without it, Tuba should stop before showing or reporting new solver results.
