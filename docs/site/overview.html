Overview

Tuba v4

Tuba is an open-source Python project for piping analysis workflows: describe the model, run Code_Aster, and inspect the processed artifacts.

Scope

Tuba keeps the engineering model in Python: pipe geometry, sections, materials, supports, loads, operating cases, and the data needed to prepare a Code_Aster study.

The project also contains result-display paths for solved artifacts: a PyVista quick-look path for notebooks and export, and a Three.js viewer for reviewable scene bundles.

What this site can show

The online pages can explain the workflow and load preserved result artifacts. They are useful for orientation and review, but they are not a hosted solver.

Result boundary

Stress, displacement, reaction, compliance, and deformed-state views should come from Code_Aster runs or imported Code_Aster artifacts. Exported .comm, .mail, and .export files are a handoff, not completed results.
