Local examples

These are the runnable scripts under examples/, ordered start-here first. None of them launch Code_Aster: they author models, route, export handoff studies, and write review files. Result review comes from the two examples that read preserved solver artifacts. Run any with python examples/<name>.py; outputs land under routing_reports/, runs/, or a scene-bundle directory, and each prints a short summary.

Example What it demonstrates Needs a solve? Related manual page
demo.py Expansion-loop demo and end-to-end workflow verification. A good first run. No — export only Tutorial
autorouting_basic.py A basic pipe autorouting run that writes review files. No — export only Autorouting
autoroute_single_pipe.py Single-pipe autorouting with study export and report output. No — export only Autorouting
autoroute_network.py Multi-pipe autorouting with network conflict reporting. No — export only Autorouting
autoroute_expansion_loop.py Hot-line route request, obstacle clearance, expansion-loop candidate, and solver-loop export/scoring configuration. No — export only Autorouting
operating_state_clash.py Operating-state geometry, clearance checks, and clash review metadata. No — export only Overview
future_ready_semantic_workflow.py Authoring, rack bay, semantic insulation, quantities, BOM, route cost, support load paths, rules, and benchmark output. No — export only Commands
imported_component_mixed_system.py Connect a custom STEP/STL component to a programmatic Tuba pipe model. No — export only Modeling
realtime_visualization_review.py Scene-bundle generation for the browser viewer. Reads a preserved result state Tutorial
code_aster_artifact_review.py Import of existing Code_Aster artifacts into result and review surfaces. Reads preserved artifacts Tutorial

Autorouting example outputs

Autorouting examples write review evidence below routing_reports/. Expect route_report.md, route_result.json, and candidate study.* files when study export is enabled. Those study files remain solver handoff artifacts until Code_Aster runs. 

.\.venv\Scripts\python.exe examples\autoroute_single_pipe.py
.\.venv\Scripts\python.exe examples\autoroute_network.py
.\.venv\Scripts\python.exe examples\autoroute_expansion_loop.py

Read the autorouting manual for the request fields, grid behavior, solver-loop options, expansion-loop limits, and report contents.

Open autorouting manual

Example rule

Examples may export studies without Code_Aster for diagnostics, but they must label that as incomplete engineering evaluation. Examples that display stresses, reactions, displacements, or compliance output must import real Code_Aster artifacts or run the real solver.
