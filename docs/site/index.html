How the manual is organized

The site follows a documentation split used by mature technical manuals: the tutorial teaches the first complete workflow, workflow pages solve concrete tasks, command pages provide reference facts, and overview/developer pages explain design boundaries. That structure is why the first page is now a real analysis path instead of a high-level product summary.

What this page is allowed to show

The browser page can document workflows and load preserved scene bundles. It does not run Code_Aster in the browser. Any page that shows stress, displacement, reaction, compliance, or deformed-state results must use Code_Aster-backed artifacts or stop at a runtime requirement.
