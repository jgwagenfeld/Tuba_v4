Command reference

Current v4 API surface

This reference covers the shipped v4 commands people need first. It replaces the old v2 command-list style with the current Python API.

Model commands

Command Purpose Typical use
Model(project_name, standard="ASME_B31.3") Create the pipe-native engineering model. model = Model("PumpLine")
add_material(...) Add elastic, density, expansion, and allowable-stress data. model.add_material("Steel", E=210e9, nu=0.3, rho=7850)
add_pipe_section(...) Add circular pipe section geometry. model.add_pipe_section("DN100", OD=0.1143, WT=0.00602)
add_rectangular_section(...), add_ibeam_section(...) Add support/rack and beam-like sections. Use for racks, frames, beams, bars, and mixed systems.
add_support(node, type=...) Add support metadata at a node. model.add_support(node="N0", type="rest")
add_obstacle(...) Register clearance obstacles for routing and clash review. Use cuboid or imported geometry obstacles before autorouting.
validate() Run structural checks before export. Call before a Code_Aster study is written.

Pipe builder commands

Builder commands run inside with model.pipe(section, material, route=...) as b:. They create nodes, elements, bend records, support metadata, and route/station data.

Command Purpose
start(point, direction=None, support=None)Start a run at a 3D point, optionally with initial direction and support.
run(length)Create a straight pipe segment in the current direction.
bend(radius, angle_deg, plane="xy")Create a bend by angle and plane.
bend_to(point, radius, plane_normal)Create a bend toward a target point with explicit plane normal.
bend_in_plane(radius, angle_deg, plane)Create an in-plane bend using a named plane.
bend_by_orientation(radius, angle_deg, orientation_deg)Create a bend from orientation angles.
add_support(type=...), spring(...)Add local support or spring metadata on the active point.
beam(length), bar(length), cable(length)Create non-pipe line elements through the same cursor workflow.
set_direction(vector)Change the builder direction for the next run.
end(support=None)Finish the run and optionally add an end support.

Operating-state commands

Uniform operation

hot = model.define_operation(
    "Hot",
    gravity=True,
    pressure=1.6e6,
    temperature=180.0,
    ref_temperature=20.0,
)

Route/station field

hot.add_field(
    "temperature",
    140.0,
    route_id="P-100",
    station_start=0.0,
    station_end=1.5,
)

Supported operation-field quantities are pressure, temperature, and wind. Linear route/station temperature fields are exported as per-element midpoint assignments. Non-uniform pressure, non-uniform wind, and piecewise profiles fail validation before export.

Solver and artifact commands

Command Purpose
CodeAsterSolver(...) Create the Code_Aster adapter with work directory and runtime options.
export_analysis_study(model, load_case, output_dir) Write .mail, .comm, .export, manifest, and sidecar files.
solve_exported_study(model, study) Execute a previously exported study and parse result artifacts.
parse_result_artifacts(model, root, load_case) Read existing Code_Aster result tables without starting a solver.
import_code_aster_artifacts(...) Import a solved artifact directory into a reviewable artifact object.
load_or_run_code_aster_results(...) Notebook helper that either runs Code_Aster or stops if required artifacts are missing.
