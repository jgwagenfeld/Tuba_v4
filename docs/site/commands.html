Command reference

Current v4 API surface

This reference covers the shipped v4 commands people need first. It replaces the old v2 command-list style with the current Python API: model authoring, pipe-builder functions, operating states, autorouting, Code_Aster artifacts, and result review.

Model commands

Command Purpose Typical use
Model(project_name, standard="ASME_B31.3") Create the pipe-native engineering model. model = Model("PumpLine")
add_material(...) Add elastic, density, expansion, and allowable-stress data. model.add_material("Steel", E=210e9, nu=0.3, rho=7850)
add_pipe_section(...) Add circular pipe section geometry. model.add_pipe_section("DN100", OD=0.1143, WT=0.00602)
add_rectangular_section(...), add_ibeam_section(...) Add support/rack and beam-like sections. Use for racks, frames, beams, bars, and mixed systems.
add_support(node, type=...) Add support metadata at a node. model.add_support(node="N0", type="rest")
add_obstacle(...) Register clearance obstacles for routing and clash review. Use cuboid or imported geometry obstacles before autorouting.
validate() Run structural checks before export. Call before a Code_Aster study is written.

Pipe builder commands

Builder commands run inside with model.pipe(section, material, route=...) as b:. They create nodes, elements, bend records, support metadata, and route/station data.

Command Purpose
start(point, support=None)Start a run at a 3D point and optionally add a support at the start node.
set_direction(direction)Set the current forward direction for the next run.
run(length)Create a straight pipe segment in the current direction.
bend(radius, angle, plane="XY")Create a bend by angle in the named plane.
bend_to(point, radius, plane_normal=None)Create a circular bend ending at a target point.
bend_in_plane(radius, angle, normal)Create a bend whose plane is defined by a normal vector.
bend_by_orientation(radius, angle, axis)Create a bend by rotating around an explicit axis vector.
add_support(type=...), spring(...)Add support or six-DOF spring metadata on the active point.
beam(length), bar(length), cable(length)Create non-pipe line elements through the same cursor workflow.
end(point=None, support=None)Finish the run, optionally close with a straight segment, and optionally add an end support.

Operating-state commands

Uniform operation

hot = model.define_operation(
    "Hot",
    gravity=True,
    pressure=1.6e6,
    temperature=180.0,
    ref_temperature=20.0,
)

Route/station field

hot.add_field(
    "temperature",
    140.0,
    route_id="P-100",
    station_start=0.0,
    station_end=1.5,
)

Supported operation-field quantities are pressure, temperature, and wind. Linear route/station temperature fields are exported as per-element midpoint assignments. Non-uniform pressure, non-uniform wind, and piecewise profiles fail validation before export.

Autorouting commands

Autorouting commands create and review route candidates. They do not make a stress or compliance claim unless a candidate study is solved with Code_Aster and the generated artifacts are imported.

Command Purpose Main gotcha
RouteEndpoint(id, point, direction=None, min_straight=0.0) Define start or goal geometry for a routed pipe. Directions are snapped to the dominant grid axis by GridRouter.
RoutingGridSpec(cell_size, bounds_min, bounds_max, margin) Configure the bounded occupancy grid used by A* search. Too-small cells over large bounds can exceed max_cells.
RoutingConstraints(clearance, insulation_thickness, min_bend_radius) Define clearance envelope and geometric route limits. Applying or visualizing routed bends requires a bend radius.
PipeRouteRequest(...) Bundle endpoints, section, material, constraints, costs, routing space, and thermal/solver metadata. The section and material must already exist on the model.
GridRouter(...).route(model, request) Generate deterministic A* candidates and select the lowest-cost valid one. It routes centerlines; it is not a construction or stress signoff.
ExpansionAwareRouter(...).route(model, request) Merge normal grid candidates with generated expansion-loop candidates. The current generator emits U-loops only.
NetworkRouter(...).route_network(model, request) Route several pipes in a deterministic priority order and report unresolved conflicts. This is sequential routing with repair attempts, not global optimization.
AutoroutingAgent(...).route_pipe(...) Run routing, solver-loop scoring/export, optional model mutation, and report writing. run_solver=False creates handoff studies only.
write_route_report(result, output_dir) Write route_report.md and route_result.json. Report diagnostics are review inputs, not automatic engineering approval.

Solver and artifact commands

Command Purpose
CodeAsterSolver(...) Create the Code_Aster adapter with work directory and runtime options.
export_analysis_study(model, load_case, output_dir) Write .mail, .comm, .export, manifest, and sidecar files.
solve_exported_study(model, study) Execute a previously exported study and parse result artifacts.
parse_result_artifacts(model, root, load_case) Read existing Code_Aster result tables without starting a solver.
import_code_aster_artifacts(...) Import a solved artifact directory into a reviewable artifact object.
load_or_run_code_aster_results(...) Notebook helper that either runs Code_Aster or stops if required artifacts are missing.
